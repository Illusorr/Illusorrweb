This is a model, not the product. The platform shipped in 2021 as a multi-user environment; what you are walking through is a single-player reconstruction built to show how it worked — the HUD, icons and destination set are taken from the original design files, the world around them is a stand-in.

A multi-user immersive environment. Five destinations, an avatar carried between all of them, and a single bar holding everything a guest can do — inventory, screen share, voice and chat — so you never leave the space to use the space.

All five destinations are ILLUSORR’s own, built on one set of rails so a new world never forks the product.
